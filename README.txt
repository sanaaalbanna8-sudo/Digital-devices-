دليل الأجهزة الرقمية — عرض تفاعلي
================================

افتح الملف:
  index.html

أو شغّل من المجلد:
  python -m http.server 8765
ثم زر:
  http://localhost:8765

الأقسام
--------
1. البداية: هدف الوحدة والحواسيب المخفية في الحياة اليومية
2. معرض الأجهزة: 18 جهازًا/نظامًا مع صورة ووصف وقرار مؤسسي
3. مختبر القرار: سيناريوهات اختيار بين البدائل
4. المصطلحات: لغة السياسات والإجراءات وأصحاب المصلحة
5. اختبر نفسك: أسئلة اتخاذ قرار

المصدر التعليمي: الوحدة 1 — أنظمة تكنولوجيا المعلومات (الإستراتيجية والإدارة والبنية الأساسية)
